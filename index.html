Comandos Essenciais

git init

Inicia um novo projeto

git add .

O primeiro comando para salvar

git commit -m "[Mensagem de Commit]"

Deixar uma mensagem para relembra da últama vez que atualizou a página

git push -u origin main

Enviar os seus commits salvos no repositório local para um repositório remoto

git fetch

Verifica se o repositório remoto tem modificações em relação ao local

git pull

Baixar as útimas alterações recentes

git clone [link do repositorio]

Criar uma cópia completa e local de um repositório existente na sua máquina

git remote add origin [link do repositorio]

Conecta o repositório local ao repositório remoto

Dica: [lembrem dos git para dar os comandos, e os commits támbem são improtantes]
